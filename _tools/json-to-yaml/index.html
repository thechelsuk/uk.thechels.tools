The result updates as you type. - Copy or download the result. about: | JSON and YAML describe the same kinds of data, but YAML is easier to read and edit by hand, which is why it's used for config files in tools like GitHub Actions, Docker Compose and Kubernetes. This converts between them using the open source [js-yaml](/sbom#js-yaml) library. - **Block** is the everyday YAML style: one key per line, nested with indentation. - **Flow** keeps the top level as blocks but writes nested objects and lists on one line, like JSON. It's compact for short values. - **Quoted** puts every string in double quotes, so nothing can be misread. Watch for strings like `y`, `no`, `on` or `off`. Older YAML readers treat those as true or false, so js-yaml quotes them automatically. It's known as the "Norway problem", after the country code `NO`. faq: - q: Are comments kept when converting YAML to JSON? a: No. JSON has no comments, so they're dropped. - q: Why does my YAML have quotes I didn't expect? a: Values that YAML could read as a number, date or true/false are quoted so they stay strings. related: [/json-pretty-printer, /yaml-explorer] config: sample: "{\"models\":[{\"provider\":\"gemini\",\"model_id\":\"gemini-1.5-flash\",\"tiers\":[{\"max_tokens\":128000,\"input_cost\":7,\"output_cost\":30}]}],\"country\":\"NO\"}" ---
