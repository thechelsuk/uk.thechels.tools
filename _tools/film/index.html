Runs in your browser." vendor: [js-yaml] scripts: [app.js] how_to: - Press **Load YAML** and choose your film list. Load more files to add to it. - Start typing a title. Close spellings still match. - Your list is kept in this browser, so next time you can search straight away. about: | Made for a simple question in front of a streaming menu: *have I seen this?* Load a YAML list of films and it searches as you type. Titles containing what you've typed come first; after that, the closest spellings, so "Dutchess" still finds *Duchess*. The file should be a YAML list where each film has a `Title`, and optionally `Year`, `Imdb` and `Rating`, in any letter case: ```yaml - Title: Duchess Year: 2024 Imdb: tt18300732 Rating: 10 ``` Loading another file merges it in: films with the same IMDb ID (or the same title and year) are updated rather than duplicated. The list is stored only in this browser. faq: - q: Where does the list come from? a: Any YAML file in the format shown. This site's own one is generated by a local script from a film log. - q: How do I remove everything? a: Press **Clear all** to delete the stored list from this browser. related: [/yaml-explorer, /podcast-grid] config: storage_key: filmList ---
