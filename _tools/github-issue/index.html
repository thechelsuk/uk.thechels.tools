--- title: GitHub Issue to Markdown permalink: /github-issue category: planning tags: [github, markdown, developer] added: 2025-03-12 summary: Turn a GitHub issue or pull request and all its comments into one Markdown document. description: "Free GitHub issue exporter. Paste an issue or pull request URL to get the title, description and every comment as clean Markdown, ready to copy or download." scripts: [app.js] services: [GitHub API] how_to: - Paste the URL of a GitHub issue or pull request. - For private repositories, or if you hit the rate limit, add a personal access token. - Press **Fetch**, then copy or download the Markdown. about: | Long issue threads are hard to read, share or feed into notes. This fetches an issue or pull request from the GitHub API and lays out the title, details, description and every comment as one tidy Markdown file, with each comment headed by its author and time. Public repositories work without signing in, but GitHub allows only 60 requests an hour that way. A [personal access token](https://github.com/settings/tokens) with read access raises that limit and lets you export private issues. The token is sent only to `api.github.com`, and it's only remembered on this device if you tick **Remember token**. faq: - q: Why do I get "rate limit exceeded"? a: GitHub limits requests without a token to 60 an hour per network. Add a token to continue. - q: Are pull request review comments included? a: The conversation comments are. Comments on specific lines of code in a review aren't. related: [/json-pretty-printer, /extract-urls] ---
