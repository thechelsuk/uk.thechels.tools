The slider jumps from 12 to 24, 32 and 64 characters for when you need something closer to a token. Characters are picked with the browser's cryptographic random number generator rather than `Math.random`, so slugs aren't predictable. Starting with a letter matters for HTML IDs and many programming languages, which don't allow names to begin with a digit. faq: - q: How likely is a clash? a: A 12-character slug has 36 possible characters in most positions, giving trillions of combinations. For a few thousand slugs a clash is vanishingly unlikely; use 24 or more if you're generating millions. - q: Are these safe to use as passwords? a: They're random, but use a password manager for passwords; it can include symbols and remember them for you. related: [/string-sorter, /lorem] ---
