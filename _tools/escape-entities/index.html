--- title: Escape HTML Entities permalink: /escape-entities category: formatters tags: [html, developer, text] added: 2025-03-12 summary: Turn <, >, &, " and ' into HTML entities so text shows as code, or turn them back. description: "Free HTML entity escaper. Convert <, >, &, quotes and apostrophes to HTML entities, or unescape them, as you type in your browser." scripts: [app.js] how_to: - Choose **Escape** or **Unescape**. - Paste text into **Input**. The result updates as you type. - Copy the result. about: | To show HTML or XML as text on a web page, in a blog post or in documentation, the characters that start tags and entities have to be written as entities, or the browser treats them as markup. Escaping changes five characters: | Character | Becomes | |---|---| | `&` | `&amp;` | | `<` | `&lt;` | | `>` | `&gt;` | | `"` | `&quot;` | | `'` | `&#39;` | **Unescape** does the reverse, one level at a time, so `&amp;lt;` becomes `&lt;`. Everything happens in your browser. faq: - q: Why only five characters? a: They're the only ones with special meaning in HTML text and attributes. Other characters, like accented letters or emoji, display fine in a UTF-8 page. - q: Is this enough to make user input safe? a: Escaping these characters is what stops text being read as HTML, but if you're building a site, use your framework's own escaping rather than copying text through a tool. related: [/json-pretty-printer, /extract-urls] ---
