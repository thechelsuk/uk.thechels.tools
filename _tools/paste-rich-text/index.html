Paste formatted text from a web page, Word or Google Docs to see and copy its HTML, optionally without styles or classes." scripts: [app.js] how_to: - Copy formatted text from a web page, Word, Google Docs or an email. - Click in the **Paste here** box and paste with Ctrl+V or ⌘V. - Tick **Remove styles and classes** for cleaner markup, then copy the HTML. about: | When you copy formatted text, your clipboard holds an HTML version alongside the plain text. This shows that HTML so you can reuse the headings, lists, links and bold text in a CMS, an email template or Markdown converter. Word processors add a lot of noise: inline styles, class names, and Office-specific tags and comments. **Remove styles and classes** strips those and keeps the structure. The preview is shown in a sandboxed frame where scripts can't run, so pasting something unexpected is harmless. Nothing is uploaded. faq: - q: Why is the HTML so long? a: Pasting from Word or a web page carries every inline style with it. Turn on **Remove styles and classes** to cut it down. - q: Why is nothing captured? a: Some apps only put plain text on the clipboard. Try copying from a browser or a different app. related: [/escape-entities, /extract-urls] ---
