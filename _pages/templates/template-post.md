A regular post is an everyday blog entry: news, an app update, or anything else you want to write about. The front matter at the top tells Jekyll how to file and show it.

This is the template I start each one from. Copy it into a new post, then fill in each part.

## What goes in each part

- **Title:** the post's headline.
- **Author:** who wrote it.
- **Tags:** a list of topics, such as `news` or `app`, used to group related posts.
- **Date:** the publish date, written as `YYYY-MM-DD`.
- **Type:** `blog`, marking it as a regular post rather than a mixtape or linked post.
- **Content:** the post itself, below the front matter.

## The template

```markdown
---
title: post title
author: name
tags: [news, app]
date: YYYY-MM-DD
type: blog
---

content
```
